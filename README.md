## 🚀 Features

*   **Global Opportunity Portal:** A centralized platform for students to find and track fully funded international scholarships.
*   **Modern Frontend:** Blazing fast development server and optimized build processes powered by Vite.
*   **API Integration:** Configurable environment variables for easy switching between local development and production backend environments.
*   **Seamless Deployment:** Fully deployed and operational in production.

## 🛠️ Tech Stack

*   **Frontend:** Vite, HTML, CSS, JavaScript
*   **Backend / API:** Node.js 
*   **Package Manager:** npm
